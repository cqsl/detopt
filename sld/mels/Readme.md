Library to compute matrix elements between non-orthogonal slater determinants, hand-optimized version.

Features:
  - support for GHF-type and UHF-type determinants
  - Generic "stable" implementation (no constraints on orthogonality) and optimized "unstable" non-orthogonal implenentation
  - overlap, matrix elements of H, and matrix elements of H^2
  - Gradients and Hessians of the matrix elements (except H^2)
